# Guante sensorizado con ESP32 para teleoperacion inalambrica de una mano robotica
Teleoperación inalámbrica de una mano robótica por medio de un guante sensorizado, usando el protocolo de comunicación ESP-NOW
Estos codigos complementan a un articulo que sera publicado en Enero del 2027 por la revista Padi
Los códigos fueron realizados en ESP-IDF así como las librerias, por lo que está hecho para una placa de desarrollo ESP32 de 38 pines
